# 交差点右折シミュレーター / Right-Turn Intersection Sim (MuJoCo web)

片側2車線・信号付きの典型的な交差点で、オレンジの自車が右折します。対向車線からは乗用車・トラック・バイクが
ランダムに来て、横断歩道を歩行者と自転車が渡ります。衝突は MuJoCo（公式 `@mujoco/mujoco` WASM）が解き、
衝突後も車・バイク・人は物理法則のまま動き続けます（スピン、横転、ライダーの投げ出し、二次衝突）。
描画は three.js。構成は N54 Monaco Drive を踏襲しています。

```sh
npm install
npm run dev           # Web 開発サーバー (http://localhost:5173)
npm run build         # 静的サイトビルド dist/
npm run tauri dev     # デスクトップアプリの開発起動
npm run tauri build   # デスクトップアプリ（macOS .dmg / .app）のパッケージング
npm test              # Node でのヘッドレス検証（右折・交通流・事故の再現）
```

## 使い方

- **自車の運転**: 🤖 自動（自動で右折。対向車との間隔を見て判断）/ 🦶 ペダル（ハンドルは自動、アクセル・維持・ブレーキで
  右折のタイミングを自分で決める）/ 🎮 手動（ハンドルも操作）
- **カメラ**: 🪟 運転席（死角の体験用）/ 🚗 後方 / 🎥 自由（マウスで回転・ズーム）/ 📹 定点（南東の角）。
  左上は上空図で、運転者の視線を表示します（緑 = 見えている、赤 = 他の車の陰で見えない）。
- **👁 視線**: 視線をメイン画面にも表示。HUD の「👁 n 死角」は、いま見えていない対向車などの数。
- **⚙ 交通設定**: 対向車・交差道路の量、速度、トラック / バイクの割合、歩行者・自転車の数、
  自車が待つ間隔、反応時間、黄信号で突っ込む車の割合。設定はブラウザに保存されます。
- **再生速度**: ¼× / ½× / 1× / 2×。衝突の瞬間はスローで見るのがおすすめ。
- **衝突**: 警報音とバナー、上空図の赤いリング、右の衝突ログ。シミュレーションは止まらず、
  事故車は数秒後にレッカー移動、自車は8秒後に再スタートします。

キー: Enter 開始/停止 · M モード · V カメラ · S 設定 · G 視線 · 1〜4 速度 · L 言語 ·
Space/W 加速 · H 維持 · B ブレーキ · ←/→ ハンドル（手動）

URL オプション: `?mode=auto&view=driver&lang=ja&rate=0.5&autostart`。交通設定も指定できます
（例 `?gap=1.5&speed=65&motoPct=40&reaction=1.4` で事故が起きやすい設定。URL 指定は保存されません）。

## 事故が起きる仕組み

事故はスクリプトではなく、判断ミスと物理の結果として起きます。

- **死角**: 自車の「見えている」判定は `mj_ray` で運転席の目から相手へ光線を飛ばして決めます。対向の内側車線の車や
  右折待ちのトラックの陰にいるバイクは見えず、見えないものは判断に入りません（右直事故）。
- **間隔の判断**: 対向車が衝突点に着くまでの時間が「自車が待つ間隔」より短いと待ちます。短くすると事故が増えます。
- **反応時間**: 相手の車は、進路に何かが入ってから反応時間だけ遅れてブレーキを踏みます。
- **黄信号**: 止まれない車と、一定割合の「突っ込む」運転者は黄信号でも進入します。

## 構成

| ファイル | 役割 |
|---|---|
| `src/layout.ts` | 交差点の寸法（左側通行）、車線・横断歩道の経路、信号サイクル（右折矢印つき）、街並みの配置 |
| `src/world.ts` | MJCF: 地面・縁石・建物・電柱・信号柱、車両プール（乗用車・トラック・バイク・自転車・歩行者） |
| `src/sim.ts` | 出現と退場、信号、運転者・歩行者の制御、右折の間隔判断、視認（`mj_ray`）、衝突検出と衝突後の処理 |
| `src/render.ts` | three.js: MuJoCo の形状、路面標示、建物と看板、街路樹、電線、信号灯、視線、衝突リング |
| `src/main.ts`, `index.html` | UI、カメラ、HUD、設定、警報 |
| `src/i18n.ts` | 日本語 / English |

物理モデルの要点:

- 乗用車・トラックは自分の車輪で走ります（前輪の操舵 + 4輪の速度アクチュエータ、タイヤ接地は摩擦つき球）。
- バイク・自転車・歩行者は、衝突までは `xfrc_applied` の力で経路に沿って動かします。歩行者は関節（股・膝・肩）を持ち、
  歩行動作をします。ライダーは別の剛体で、座席に weld 拘束されています。
- 衝突した瞬間に制御を切ります。ライダーの weld を外し（投げ出される）、人の関節は脱力し、車の運転者はブレーキを踏みます。
  あとは MuJoCo がすべてを計算します。
- 使っていないエージェントは遠くに浮かせて（重力補償・衝突なし）待機させ、出現時に瞬間移動させます。
  MuJoCo のモデルは実行中に物体を増やせないためです。
- 衝突の分類: 車両は `contype 1 / conaffinity 3`、歩行者と自転車は `2 / 1`。人どうしはすり抜け、車両・建物とは衝突します。
  はねられた人はしばらく全てと衝突するようになり、他の人に当たることもあります。

MuJoCo は剛体なので、車体のへこみ（塑性変形）は計算しません。
